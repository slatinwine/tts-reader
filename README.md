# 澹读 · 有声阅读

一个纯本地的网页版文本朗读（TTS）阅读器：导入 TXT 或 Markdown 文本，浏览器原生语音逐句朗读，当前句高亮跟随，清水混凝土风极简界面。全部功能离线运行，无需任何 API Key。

## ✨ 功能特性

- 多种导入方式：按钮选择 `.txt` / `.md` 文件、从剪贴板导入、直接把文件拖进阅读区
- 按句切分朗读：按中英文句末标点智能断句，保留段落结构，Markdown `#` 标题行单独渲染
- 当前句高亮与自动滚动：正在朗读的句子反色高亮，阅读区自动平滑滚动跟随
- 点击句子跳读：点击任意句子即可从该句开始朗读
- 朗读控制：播放/暂停、上一句/下一句、停止、进度条显示
- 细致的可调参数：语音列表（优先本地普通话）、语速 0.5-3 倍、音调、音量
- 记住文本：可选将文本存入 localStorage，下次打开继续读
- 响应式布局：桌面端常驻侧栏、移动端抽屉式侧栏 + 遮罩

## 🚀 使用方法

1. 用浏览器直接打开 `index.html`
2. 点击左侧「导入 .txt 文件」或直接拖拽文件到阅读区，也可从剪贴板导入
3. 在左侧「朗读」面板选择语音、调节语速/音调/音量，点击底部播放按钮开始聆听

> 朗读由浏览器内置的 Web Speech API 提供，可用语音取决于操作系统与浏览器；请使用 Chrome / Edge 等支持语音合成的现代浏览器。

## 🛠️ 技术栈

- HTML / CSS / 原生 JavaScript（单文件，无依赖、无构建）
- Web Speech API（`speechSynthesis`）本地语音合成
- File API / Clipboard API / localStorage
